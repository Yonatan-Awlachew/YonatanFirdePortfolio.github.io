Featured

PDF Q&A Assistant (RAG API)

A Retrieval-Augmented Generation API that answers natural-language questions about PDF documents with source citations. Built with FastAPI, Groq for fast LLM inference, and Gemini embeddings, backed by a pytest test suite.

Cinema Ticket Booking System

A full-stack seat-booking platform: an ASP.NET Core 9 Web API secured with JWT authentication and Entity Framework Core/MySQL, paired with a React 19 single-page frontend. Seat reservations are protected against double-booking at the database level, with optimistic concurrency control on profile edits.
